Build a Number Guessing Game – Java

 Project Overview

The Number Guessing Game is a simple console-based Java application developed as part of my Java Programming Internship at Veda Technology.

In this game, the computer generates a random number between 1 and 100, and the user tries to guess the correct number. The program provides hints to help the user guess correctly.

🎯 Objectives

- Learn random number generation in Java.
- Understand loops and conditional statements.
- Practice user input using the Scanner class.
- Count the number of attempts taken by the user.

🛠️ Technologies Used

- Programming Language: Java
- Random Number Generation: "java.util.Random"
- User Input: "java.util.Scanner"
- Concepts: Loops, if-else conditions, and variables.

✨ Features

- Generates a random number between 1 and 100.
- Accepts guesses from the user.
- Displays "Too low!" when the guess is smaller than the secret number.
- Displays "Too high!" when the guess is greater than the secret number.
- Continues until the correct number is guessed.
- Displays the total number of attempts.

▶️ How to Run

1. Install Java or open an online Java compiler.
2. Create a Java file named "Task3.java".
3. Copy the program code into the file.
4. Compile and run the program.
5. Enter your guesses between 1 and 100.
6. Continue guessing until you find the correct number.
